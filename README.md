[Bend](https://bend-lang.com) grammar for [tree-sitter](https://github.com/tree-sitter/tree-sitter).

The grammar follows the syntax notes at the top of [bend.ts](https://github.com/bendlang/bend/blob/main/bend2/bend.ts)
and the [guide](https://github.com/bendlang/bend/blob/main/guide/GUIDE.md).
